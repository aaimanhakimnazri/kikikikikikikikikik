
# UNIFORM TRACKER
### Commander Management System

Uniform Tracker is a web-based management system designed to manage commander information, attendance records, grades, and performance reports.

## Live demo and repository

- Live site (GitHub Pages): `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`
- Repository: `https://github.com/YOUR-USERNAME/YOUR-REPO-NAME`

## Project Overview

The system provides a centralized platform for officers to manage commander records and for commanders to monitor their own attendance and academic performance.

## System Features

### Officer
- Dashboard and system statistics
- Commander Management (Add, Edit, Delete)
- Manage attendance records
- Manage grade records
- View Reports & Analytics
- Reset commander passwords

### Commander
- Personal Dashboard
- Submit and view personal attendance
- View personal grades
- View personal reports
- Change password

## User Roles

| Role | Access |
|---|---|
| Officer | Full system management |
| Commander | Personal records and information |

## Installation

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` using a web browser.
4. Log in using an authorized account.

## Data Storage

The system uses browser LocalStorage to store user accounts, attendance records, and grade records.

**Note:** LocalStorage data is stored in the user's browser and is not synchronized between different devices.
